# Digi Draw
___NOTE: This project is in its initial stages of development. Come back later for a more complete version.___

This repository serves as a guide to creating a Digi Draw, which is a small device consisting of a Raspberry Pi Pico, a small display, a couple of sensors, and some 3D-printed parts.

## Development Roadmap
The following tasks outline the future development of the project. Completed tasks that involve the creation of features will be moved to the [Features](#features) section.

* Initial Project Setup
    * Create project file structure
    * Input Waveshare's driver files
    * Configure and test the build
    * Test flashing the project to the `Pico`
* Create a wrapper for Waveshare's driver
* Create a class for getting encoder input
* Reference CAD files for 3D-printed parts
* Write a full manual that describes the project's
    * Set-up procedure
    * Software
    * Hardware (including 3D printed parts)
* Update the README so it provides an overview of the project
